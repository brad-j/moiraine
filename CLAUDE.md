# moiraine

The app for gaidin (`../gaidin`). Read gaidin's `docs/plan.md`, "Design: the app", before changing anything: it records what was decided with Brad and the order of work.

- moiraine is a client only. No server functions, server routes or SSR: gaidin is the server, and its HTTP API (`Gets`, `Posts` and `StreamEvent` in gaidin's `src/web.ts`) is the one interface. A change the app needs from the server is made in gaidin, in its own commit there.
- Import gaidin only with `import type` from `gaidin/src/web.ts`, through `src/api.ts`. Nothing of gaidin's may end up in the build.
- `src/routeTree.gen.ts` is generated by the router plugin on build and dev; don't edit it.
- Look and feel follow gaidin's web view (`src/styles.css` carries its tokens) and Brad's UI defaults. Borrow nothing from other assistants' apps, including names.
- `pnpm check` before calling a change done. Check UI changes in a browser against `pnpm dev:faux`.
